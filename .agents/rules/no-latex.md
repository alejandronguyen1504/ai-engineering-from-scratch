# Communication & Formatting Rule: No LaTeX in Chat Responses

- **Do NOT use LaTeX math syntax or delimiters** (`$...$` or `$$...$$`) when communicating with the user in the chat UI. The user's chat client does not render LaTeX and produces font/formatting glitches.
- **Always format mathematics using**:
  1. Plain text with Unicode math symbols: `∈`, `≤`, `≥`, `∑`, `∏`, `√`, `→`, `·`, `^`, `_`, `π`, `μ`, `σ`, `λ`.
  2. Code blocks (e.g., ```text ... ``` or inline code `` `...` ``) for complex mathematical formulas.
